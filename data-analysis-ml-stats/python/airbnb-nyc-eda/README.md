# NYC Airbnb — Exploratory Data Analysis (Python/pandas)

**What this is:** Exploratory data analysis on the real (non-synthetic)
NYC Airbnb Open Data (2019) dataset from Kaggle, delivered as an
executed Jupyter notebook with charts.

**Files:**
- `nyc_airbnb_eda.ipynb` — EDA notebook
- `AB_NYC_2019.csv` — raw/original data
- `airbnb_nyc_clean.csv` — cleaned data used for analysis

*Built by Mumba — Python, pandas.*
